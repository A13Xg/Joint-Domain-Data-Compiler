# Privacy

Joint Domain Data Compiler does not collect, store, or transmit any information about you or your
data. It has no accounts, analytics, telemetry, crash uploads, or advertising.

- **Your data stays on your machine.** Files you import are processed locally, in the browser or
  the desktop app. Nothing you load is sent anywhere.
- **Map tiles.** If you choose a network basemap (the default), the map requests tile images from
  OpenStreetMap, CARTO, or OpenTopoMap, as any web map does. Those servers see your IP address and
  which map area you are viewing, under their own privacy policies. Choose the **offline grid**
  basemap to make no network requests at all.
- **Desktop app only:** it may download the Special Use Airspace overlay from this project's
  GitHub repository when it is missing, and it keeps logs and crash dumps **on your machine only**
  (`%APPDATA%\joint-domain-data-compiler\logs` on Windows). Nothing is uploaded; you decide whether
  to share them.
